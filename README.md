<h1 align="center">Trader Workspace</h1>
<p align="center"><b>by VigyaanVest.com</b> · one connected workspace for active investors — Chrome &amp; Edge</p>

---

A single browser extension that brings research, an events calendar, and a live news tape
into one terminal — for **US ($)** and **India (₹)** markets. Light + Midnight themes.
**Local-first**: your watchlist, notes, and settings stay in your browser. No account, no
tracking, no servers.

- **Deck** — live quote, fundamentals (P/E, ROE, ROCE, D/E, 52-week, market cap), a chart, and your own thesis/setup/tags/review notes.
- **Grid** — your watchlist as a sortable screener with sparklines, next-event countdowns, and an "in the news" count.
- **Calendar** — earnings + US Fed / India RBI events, a forward ribbon, a full Month/Week view, and desktop alerts.
- **The Tape** — a live headline stream (TradingView, Finviz, MarketWatch, Zerodha Pulse) with optional read-aloud.
- **Dock** — a side panel that reads the stock page you're viewing.
- **⌘K** — jump to any symbol, or type a ticker (`AAPL`, `TCS.NS`, `RELIANCE.BO`) to add it.

## Install (Chrome or Edge)

> Not on the Chrome Web Store / Edge Add-ons yet — install it in a couple of minutes below.

1. **Download** the extension:
   **[⬇ Download trader-workspace.zip](https://investortools.vigyaanvest.com/trader-workspace.zip)**
   (or from this repo: green **Code** button → **Download ZIP**).
2. **Unzip** it. You'll get a folder named **`trader-workspace`**.
3. Open your browser's extensions page:
   - **Chrome:** type `chrome://extensions` in the address bar and press Enter.
   - **Edge:** type `edge://extensions` and press Enter.
4. Turn on **Developer mode** (toggle, top-right in Chrome / left sidebar in Edge).
5. Click **Load unpacked** (top-left).
6. Select the unzipped **`trader-workspace`** folder and click **Select Folder**.
7. (Optional) Click the **puzzle-piece** icon in the toolbar and **pin** VigyaanVest.

Now click the **VigyaanVest** toolbar icon to open the Trader Workspace. 🎉

**Updating later:** download the new zip, unzip it (replace the old folder), then click the
**↻ refresh** icon on the extension's card in `chrome://extensions`.
